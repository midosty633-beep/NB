# مهامي — GitHub Pages

ارفع **كل الملفات الموجودة هنا** إلى جذر Repository في GitHub.

ثم:
1. Settings
2. Pages
3. Deploy from a branch
4. Branch: `main`
5. Folder: `/ (root)`
6. Save

سيكون `index.html` في الجذر مباشرة، لذلك لا تحتاج للدخول إلى مجلد آخر.

هذه نسخة الويب/PWA. الإشعارات المحلية الأصلية الخاصة بـAndroid وiOS تحتاج نسخة التطبيق الأصلية، أما المؤقتات والحفظ وباقي واجهة الويب فتعمل هنا.
